# Bypass Links

[![Deploy CI](https://github.com/amitsingh-007/bypass-links/actions/workflows/release.yml/badge.svg)](https://github.com/amitsingh-007/bypass-links/actions/workflows/release.yml) ![GitHub downloads](https://img.shields.io/github/downloads/amitsingh-007/bypass-links/total?color=success) ![License](https://img.shields.io/github/license/amitsingh-007/bypass-links?color=blue)

⚠️ Not open for new signups ⚠️

Bypass Links is an open-source extension for desktop Chrome. Save bookmarks in folders, tag them with people, create URL shortcuts, and use tools for supported forums. It can also skip intermediary links on supported pages.

Features that sync bookmarks, people, shortcuts, and forum settings require an existing account signed in with Google.

## Features

- Save bookmarks in folders and filter them by the people you tag.
- Redirect short aliases to the websites you choose.
- Open a saved group of default shortcut sites with one click.
- Open selected links from supported forum pages in their own tabs.
- Mark sites as visited and see when you last visited them.
- Monitor visited sites and clear the browser history from a monitoring period when you turn monitoring off.
- Reduce autofill suggestions in page input fields while the extension is active.
- Skip link shorteners and other intermediary pages on supported sites.

## Install

1. Download the latest ZIP from the [download page](https://bypass-links.vercel.app).
2. Unzip it and open `chrome://extensions` in desktop Chrome.
3. Turn on **Developer mode**, select **Load unpacked**, and choose the unzipped folder.
